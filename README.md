# Mr. GREEN PEST CONTROL CO.,LTD (Pest Control Management System)

เว็บแอปพลิเคชัน CRM และ ERP แบบครบวงจรสำหรับธุรกิจกำจัดปลวก ช่วยเพิ่มประสิทธิภาพการจัดการลูกค้า, การประเมินหน้างาน, การปฏิบัติงานภาคสนาม, เอกสารทางการเงิน, และคลังสินค้าในแพลตฟอร์มเดียวที่ใช้งานง่าย

## ✨ คุณสมบัติหลัก (Features)

- **แดชบอร์ด (Dashboard):** ภาพรวมข้อมูลสำคัญของธุรกิจแบบเรียลไทม์ เช่น งานที่ต้องทำวันนี้, ใบแจ้งหนี้เกินกำหนด, และสินค้าใกล้หมดสต็อก
- **การจัดการลูกค้า (Customer Management):** จัดการฐานข้อมูลลูกค้า, เพิ่ม/แก้ไขข้อมูล, และดูประวัติการใช้บริการ
- **การจัดการใบประเมิน (Assessment Management):** สร้างและติดตามสถานะใบประเมินหน้างานในรูปแบบ Kanban Board หรือ List View
- **การจัดการงานภาคสนาม (Field Operations):** วางแผน, มอบหมาย, และติดตามงานของช่างเทคนิคผ่านมุมมองปฏิทิน, Kanban Board, และ List View
- **ระบบการเงินและบัญชี (Financials):** จัดการเอกสารทางการเงินทั้งหมด ตั้งแต่ใบเสนอราคา, ใบแจ้งหนี้/ใบวางบิล, ไปจนถึงใบกำกับภาษี/ใบเสร็จรับเงิน
- **การจัดการคลังสินค้า (Inventory & Warehouse):**
  - จัดการรายการสินค้าและบริการ (Products/Services)
  - จัดการคลังสินค้าหลายแห่ง รวมถึงคลังบนรถบริการ
  - ระบบรับเข้า (Goods Receipt), เบิก (Withdrawal), โอนย้าย (Transfer), ปรับปรุง (Adjustment), และคืนสินค้า (Return)
- **การจัดการผู้ใช้งานและสิทธิ์ (Users & Roles):** กำหนดบทบาทและจัดการสิทธิ์การเข้าถึงข้อมูลส่วนต่างๆ ของระบบสำหรับผู้ใช้งานแต่ละคน

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend:** React, TypeScript
- **Styling:** Tailwind CSS
- **Charting:** Recharts
- **Module Loading:** ES Modules with Import Maps

## 🚀 การใช้งาน (Getting Started)

แอปพลิเคชันนี้ถูกออกแบบมาให้ทำงานได้ทันทีโดยไม่ต้องมีการตั้งค่าเพิ่มเติม เพียงเปิดไฟล์ `index.html` ในเบราว์เซอร์ที่รองรับ ES Modules ระบบจะทำการโหลดและแสดงผลแอปพลิเคชันโดยอัตโนมัติ

## 📂 โครงสร้างไฟล์ (File Structure)

```
.
├── components/         # ส่วนประกอบ UI ที่ใช้ซ้ำได้ เช่น Modal, Card, Form Controls
├── icons/              # ไอคอน SVG ที่ใช้ในแอปพลิเคชัน
├── pages/              # คอมโพเนนต์สำหรับแต่ละหน้าหลักของระบบ
├── App.tsx             # คอมโพเนนต์หลัก จัดการการแสดงผลหน้าต่างๆ (Routing)
├── constants.ts        # ข้อมูลจำลอง (Mock Data) และค่าคงที่ต่างๆ
├── index.html          # ไฟล์ HTML หลักสำหรับเริ่มต้นแอปพลิเคชัน
├── index.tsx           # จุดเริ่มต้นของ React Application
├── metadata.json       # ข้อมูลเกี่ยวกับแอปพลิเคชัน
├── types.ts            # ศูนย์รวม TypeScript types ทั้งหมดของโปรเจกต์
└── README.md           # เอกสารแนะนำโปรเจกต์
```
